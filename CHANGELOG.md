# Changelog

All notable changes to CRIM Flight Deck. The newest release is on top; the text of a release section becomes the
notes of its GitHub release.

## [1.0.0] - 2026-11-01

First public release.

- Tablet: virtual throttle quadrant (trim wheel, throttle / prop / mixture levers with a link handle between engine
  pairs, flaps, gear, parking brake, switches), plus AP, radio, systems and quick-action pages and an attitude indicator.
- Phone: autopilot / radios / systems / quick-action panel.
- Top bar with live flight data (speeds, altitude, vertical speed, heading, fuel, flow, endurance).
- Handles hold the value you released instead of jumping back to the simulator's lagging reading.
- Start automatically with MSFS (`scripts\autostart.ps1`), editable layouts, aircraft profiles, mock mode.
- Installer (`install.cmd`) and updater (`update.cmd`, or "Update now" on the PC admin page).
